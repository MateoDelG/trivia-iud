# FastAPI Backend

Source: https://skills.rest/skill/fastapi-backend

Use this skill when changing backend APIs.

- Keep request/response models explicit and version-safe.
- Validate inputs at API boundary and return clear `4xx` messages.
- Prefer modular files: routes, models, state/services.
- Add/update endpoint-focused tests when behavior changes.
- Preserve compatibility for existing clients unless migration is explicit.
