# Frontend Excellence

Source: https://skills.rest/skill/frontend-excellence

Use this skill for `/setup` and `/host` UI work.

- Preserve in-progress form state across refresh.
- Avoid destructive DOM rebuilds on live updates.
- Keep validation feedback clear and specific.
- Ensure mobile-safe layouts and readable content density.
- Favor simple, intentional JS/CSS over framework-heavy patterns.
